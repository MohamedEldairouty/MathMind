# 💖 Math Mind - C# WinForms Project

**Where Math Meets Mastery**

A fun and interactive MCQ-based online exam system designed for students and examiners.

---

## 👩‍🏫 Developed By:
- MohamedEldairouty

---

## 🛠 Technologies Used:
- C# (.NET Windows Forms)
- Microsoft SQL Server
- Dynamic TXT Configuration for WiFi-Based Online Mode

---

## 🎯 Features
- Real-time dashboard auto-refresh using timers
- Dynamic message boxes for alerts and quiz notifications
- Student login to take quizzes and view grades
- Examiner portal to manage quizzes, grades, and quiz requests
- Secure and maintainable local database with auto-updates

---

## 💡 Notes
- All sensitive files like config and connection strings should be handled securely.
- For online access, ensure the WiFi TXT config is properly placed and read by the application.
